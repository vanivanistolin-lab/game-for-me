# Рубеж · v0.3.1 — функции администратора

**F8** → войдите как администратор своим GAME_ADMIN_TOKEN → включайте:
- Бессмертие.
- Бесконечные патроны и гранаты.
- Стрельбу без отдачи и разброса.
- Восстановление здоровья и брони.

Функции применяет сервер только к текущему администратору. По умолчанию выключены; при потере прав больше не действуют. Все участники видят пометку «АДМИН-РЕЖИМ». Обычный игрок не может включить их себе.

**Обновите игру и сервер до v0.3.1**: сетевой протокол теперь 4. Если сервер уже на Render: Manual Deploy → Deploy latest commit. Пароль администратора остаётся прежним. Для нового бесплатного сервера: [Deploy to Render](https://render.com/deploy?repo=https://github.com/vanivanistolin-lab/game-for-me).

Windows: скачайте GameForMe.exe или установщик GameForMe-Setup.exe для C:\game. APK и Linux-сервер приложены. Godot 4.4.1 без требования SSE4.2 сохранён.

Проверены серверное бессмертие, отключение и отзыв прав, запрет функций гостю, реальная стрельба без расхода патронов и лечение. Сетевые проверки выполняются с двумя отдельными клиентами и повторяются против Docker-сервера. Реальный компьютер пользователя и его сервис Render отдельно не проверены.
