# Рубеж · v0.1.1 — совместимость со старыми процессорами

Исправлена причина остановки Windows-версии с сообщением **A CPU with SSE4.2 instruction set support is required**.

Движок и экспортные шаблоны переведены с Godot 4.6.3 на **Godot 4.4.1**, официально поддерживающий процессоры Windows x64 без SSE4.2. Игровые механики сохранены. В Android обновлены номер и название версии.

## Скачать и запустить

- **Windows:** скачайте GameForMe-Windows.zip, распакуйте его в новую папку и запустите GameForMe.exe. Также доступен отдельный GameForMe.exe. Удалите старую копию или убедитесь, что запускаете файл из этого релиза.
- **Android:** скачайте и установите GameForMe-Android.apk. Используется тестовая debug-подпись; при конфликте подписи с предыдущей версией удалите старое приложение перед установкой.
- Godot и инструменты разработки устанавливать не нужно.

## Проверки

18 автоматических проверок игровых механик прошли на Godot 4.4.1. Workflow проверяет экспорт Windows, подпись Android APK и структуру пакетов перед публикацией. Запуск на конкретном старом процессоре пользователя и реальных Android-устройствах пока не подтверждён.

## Содержимое игры

Командный бой и каждый сам за себя, семь ботов, три процедурных варианта карты, пять типов огнестрельного оружия, нож и гранаты, броня, возрождение, магазин и русский интерфейс. Ранняя версия: режим с бомбой, сетевые матчи и сложная тактика ботов пока не реализованы.
