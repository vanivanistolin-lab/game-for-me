# Рубеж · v0.3.0 — мультиплеер, администратор и графика

## Скачать

**GameForMe-Setup.exe** устанавливает игру в `C:\game`. Также доступны обычный **GameForMe.exe**, Windows ZIP и Android APK. Godot и инструменты разработки игроку не нужны.

## Бесплатный хостинг и ваш администратор

[**Нажмите Deploy to Render**](https://render.com/deploy?repo=https://github.com/vanivanistolin-lab/game-for-me), войдите в свой аккаунт Render и разверните Blueprint из ветки **main** на тарифе **Free**. Конфигурация бесплатного сервиса уже в репозитории. Сам по себе этот релиз не создаёт живой публичный адрес.

После статуса **Live**:
1. Скопируйте адрес сервиса и замените `https://` на `wss://`.
2. В игре нажмите **F8**, введите адрес и свой ник.
3. Только для себя: возьмите автоматически созданный **GAME_ADMIN_TOKEN** в разделе **Environment** вашего сервиса Render и вставьте в поле пароля администратора. Не сообщайте секрет друзьям и не публикуйте его.
4. Подключитесь и снова откройте **F8**. Вы сможете менять карту, перезапускать матч, менять количество ботов и исключать игроков. Друзьям нужен только адрес сервера.

Бесплатный сервис может засыпать после простоя и медленно запускаться. Регистрацию, доступность тарифа и его лимиты определяет Render. Это не обещание бесплатного сервера 24/7. [Подробная инструкция](https://github.com/vanivanistolin-lab/game-for-me/blob/main/hosting/README.md).

Локальный сервер также доступен: создатель автоматически администратор, друзья в той же сети подключаются по `ws://IP:24567`.

## Сетевая игра

До 8 игроков, до 6 ботов, командный бой и FFA. Сервер рассчитывает движение, попадания, здоровье, броню и патроны. Ввод ограничивается по скорости и частоте. Клиент не может назначить себе администратора без секрета. Офлайн-тренировочные функции в сетевых матчах отключены.

Это первая версия TCP/WebSocket-мультиплеера с базовой интерполяцией; без матчмейкинга, компенсации задержки и профессионального античита. Для бесплатного сервера начните с двух ботов.

## Улучшения графики

Оригинальные карты рельефа и шероховатости материалов, балконы и двери, кабели, растения, дорожные детали, трассеры, затухающие вспышки, плавное прицеливание и анимация шагов ботов. Сохранены Godot 4.4.1 без требования SSE4.2 и низкое качество для слабых компьютеров. Увеличение качества «в пять раз» не измерялось; это стилизованная независимая игра, не CS2.

## Проверки

34 проверки офлайн-механик, сравнение коллизий/навигации трёх карт, 20 проверок реального сетевого взаимодействия отдельного сервера и двух клиентов. Сетевые проверки повторяются против собранного Docker-образа, предназначенного для хостинга. CI проверяет Windows EXE, Android APK с разрешением интернета, подпись APK, Linux-сервер и установщик.

Работа именно на бесплатном сервисе вашего аккаунта Render будет подтверждена после развёртывания. Фактическая производительность на вашем старом процессоре и Android-устройстве не проверена. Режим с бомбой пока не реализован.
